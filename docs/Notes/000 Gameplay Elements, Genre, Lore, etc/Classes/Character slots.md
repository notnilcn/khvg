The game is going to both be harder and easier than RotMG. Harder in that there will be more bosses like this where group coordination would be necessary (imagine if [this](https://youtu.be/Psh3f2np4Ok?si=zOuCcC2gKdqe38fy&t=660) boss's purple shots in this phase were aggroing onto multiple targets - it'd make it unpredictable and inefficient to do the phase) but easier in that players won't have to focus on shooting (there'll be forgiving aim assist) and player items will drop and despawn after a certain amount of time if they die. There's still going to be perma death, but when players die the main source of frustration will from players losing their levels/stats/skills. It'll still be possible for players to lose their items - I plan on making the world so huge that it's practically untraversable, which makes it possible for players to be unable to retrieve their items in they died in an inconvenient spot - it just won't be a huge source of frustration for newer players.

If players want to be successful, then it will be more efficient to have multiple character slots, which will be monetised. One character slot for item retrieval, various character slots for resource gathering, and optional extra character slots for different combat roles. Character slots won't be able to be jacks of all trade - a combat character slot won't have enough skill points to spec into resource gathering. They'll have a base level of resource gathering, but if they want to optimise it then they'll have to sacrifice combat skill points for resource gathering. Resource gathering character slots will primarily be an end-game thing, and players who have a character slot that has optimized it will be highly valuable and highly targeted for pvp through pve (other guilds will want to drag enemies onto the resource gathering characters).
