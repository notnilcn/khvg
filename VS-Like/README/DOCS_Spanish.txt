Vampire Survivors Template - Godot 4.4

Introducción
Este template es una base personalizable para desarrollar juegos al estilo de Vampire Survivors utilizando Godot 4.4. Permite a los desarrolladores estudiar el código, modificarlo y expandirlo para crear sus propios proyectos.

Instalación y Configuración
1. Descarga y descomprime la carpeta del proyecto.
2. Abre Godot 4.4 e importa el proyecto.
3. Asegúrate de que todas las dependencias estén instaladas.
4. Ejecuta el proyecto para verificar que todo funcione correctamente.

Gameplay y Mecánicas
- Sistema de auto-ataque: El jugador ataca automáticamente según la cadencia de cada arma.
- Oleadas de enemigos: Aparacición de enemigos, incluyendo patrones circulares y enemigos elite.
- Objetos: Recoge objetos (puntos, cofres y comida) para mejorar armas o curar al jugador.
- Sistema de niveles: Obtén experiencia para mejorar y/o obtener armas.

Personalización y Expansión
- Añade nuevas armas: Modifica o crea armas nuevas gracias a los Custom Resources y un sistema modular adaptado.
- Crea nuevos personajes: Crea nuevos personajes (enemigos/jugable) fácilmente usando Custom Resources.
- Modifica las reglas del Spawner: Edita el código de Spawner para cambiar los tiempos de aparición y los patrones.

Optimización y Rendimiento
- PhysicsServer2D: Usado para manejar grandes números de enemigos eficientemente, manteniendo un gameplay fluido por sobre los 60 FPS.
