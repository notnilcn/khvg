This is kind of a open source bullet hell mmo game. Server isn't open source but the client is.

The game doesn't work if the server isn't running. You can ping the server using:

```
curl https://khvgames.com/server/v1/ping
```

It should return 200. If the server isn't running, then message @notnilc2107 on discord.
