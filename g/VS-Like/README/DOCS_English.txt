Vampire Survivors Template - Godot 4.4

Introduction
This template is a customizable foundation for developing Vampire Survivors-style games using Godot 4.4. It allows developers to study the code, modify it, and expand it to create their own projects.

Installation and Setup
1. Download and unzip the project folder.
2. Open Godot 4.4 and import the project.
3. Ensure all dependencies are installed.
4. Run the project to verify everything is working correctly.

Gameplay and Mechanics
- Auto-Attack System: The player attacks automatically based on weapon cooldowns.
- Enemy Waves: Enemies spawn including circular patterns and elite enemies.
- Drops: Collect drops (points, chests and food) to enhance weapons or heal the player.
- Leveling System: Gain experience to upgrade and/or obtain weapons.

Customization and Expansion
- Adding New Weapons: Modify or create weapons easily thanks to Custom Resources and an adapted modular system.
- Creating New Characters: Create new characters (enemies/playable) easily using Custom Resources.
- Modifying Spawn Rules: Edit the Spawner script to change spawn rates and patterns.

Optimization and Performance
- PhysicsServer2D: Used to efficiently manage large numbers of enemies, maintaining a smooth gameplay over 60 FPS.
